## Changelog Guidelines

For each release or meaningful update, record the date and summarize changes under one or more of these headings:

- **Added** – new features
- **Changed** – changes to existing functionality
- **Fixed** – bug fixes
- **Removed** – removed features or files
- **Security** – security-related changes
